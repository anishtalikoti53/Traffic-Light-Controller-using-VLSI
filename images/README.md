# Project Visuals

This folder contains repository visuals for the Traffic Light Controller.

- `architecture_block_diagram.svg` — project-specific RTL architecture diagram derived from the supplied Verilog source.
- `fsm_state_diagram.svg` — project-specific five-state FSM diagram derived from the supplied Verilog source.

## Waveform reference

A historical traffic-controller waveform from an external Verilog/ModelSim example is linked in the project documentation as a **reference visual only**. It is not presented as a waveform captured from this repository's original project, because the original simulation screenshot is no longer available.

External reference: IJRASSET, *Design and Simulation of an Optimized Traffic Controller Using Moore FSM*.
